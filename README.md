# MAD Online-Market-pace-
Our project is an online marketplace where buyers and sellers connect, facilitating secure transactions and product listings. It enhances user experience through account management, feedback storage, and personalized recommendations.
The marketplace aims to connect sellers and buyers, offering various items and services. Users can browse through different categories, add items to their cart, and complete transactions securely.

The marketplace allows sellers to create product listings, set prices, manage inventory, and communicate with potential buyers. Buyers can search for products, compare prices, read reviews, and make purchases.

The marketplace encourages sellers and buyers to register accounts. Registered users can manage their profiles, view order history, and receive personalized recommendations. Customer details, including names, addresses, and contact information, are stored in a separate table. Additionally, customers can provide feedback and reviews on products and sellers, which are stored in a feedback table to improve the overall user experience.
